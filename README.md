# Snake Game - Blokopdracht 2.2

Snake-game gemaakt met Python en Pygame.

## Team

- Moenes - tekenen.py, besturing.py, scherm.py

## Installeren
pip install -r requirements.txt

## Starten
python main.py

## Afspraken
- Slang = lijst van tuples, positie 0 is de kop
- Richting = tuple, bijv. (1, 0) voor rechts
- Vaste waardes staan in instellingen.py
